# Johannes Fischer — GitHub Page

Personal portfolio site. Static React SPA deployed to GitHub Pages.

## Built with

- [Vite+](https://viteplus.dev/) — unified toolchain (`vp`): Vite/Rolldown build and dev server, Oxlint, Oxfmt, Vitest, commit hooks
- [React 19](https://react.dev) — functional components, hooks
- [TypeScript](https://www.typescriptlang.org/) — strict mode
- [Panda CSS](https://panda-css.com/) — atomic CSS-in-JS, design tokens, CVA variants
- [Lucide React](https://lucide.dev/) — icons
- [Motion](https://motion.dev/) — animations
- [Storybook](https://storybook.js.org/) — component development and documentation
- [Chromatic](https://www.chromatic.com/) — visual regression testing and Storybook publishing
- [Vitest](https://vitest.dev/) + [Testing Library](https://testing-library.com/react) — unit/hook tests

## Getting started

Requires the [`vp` CLI](https://viteplus.dev/guide/).

```bash
vp install         # install dependencies
vp config          # install the git hook dispatcher
vp dev             # dev server with HMR
```

## Commands

```bash
vp dev             # dev server with HMR
vp build           # production build → dist/
vp preview         # preview production build
vp check           # format + lint + type check
vp lint            # Oxlint (config in vite.config.ts → lint)
vp fmt .           # Oxfmt (config in vite.config.ts → fmt)
vp test            # run tests with Vitest
vp run storybook   # Storybook dev server (http://localhost:6006)
vp run chromatic   # publish Storybook to Chromatic (requires .env)
vp run prepare     # regenerate Panda CSS types
```

Run `vp check && vp test` before committing. Chromatic requires a `.env` file with `CHROMATIC_PROJECT_TOKEN=<token>`.

## Commit hooks

A Vite+ `pre-commit` hook (`.vite-hooks/pre-commit` → `vp staged`) lints and formats staged files. The checks are configured in `vite.config.ts` → `staged`.

```bash
vp config          # install the git hook dispatcher (.vite-hooks/_)
vp staged          # run the staged-file checks manually
vp hooks status    # show whether hooks are active
```

## Project structure

```
src/
├── components/    # reusable UI (Button, Carousel, Header, Footer, …) + *.stories.tsx
├── sections/      # page sections (Hero, Skills, Testimonials, Career)
├── styles/        # CVA variant definitions
├── App.tsx        # root, theme provider
├── const.ts       # shared URLs and constants
└── main.tsx
styled-system/     # auto-generated by Panda CSS — do not edit
```

## Testing

Tests run with [Vitest](https://vitest.dev/) (via Vite+) in a `jsdom` environment, using `@testing-library/react` for hooks/components. Test files sit next to the code they test (`useFocusFirst.ts` → `useFocusFirst.test.ts`).

```bash
vp test            # watch mode locally, single run in CI
```

## CI & Deployment

Every pull request and push to a non-`main` branch runs lint + tests via `.github/workflows/ci.yml`.

Push to `main` → GitHub Actions builds and deploys to GitHub Pages automatically (`.github/workflows/deploy.yml`).
