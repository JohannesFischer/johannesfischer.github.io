# Johannes Fischer — GitHub Page

Personal portfolio site. Static React SPA deployed to GitHub Pages.

## Built with

- [React 19](https://react.dev) — functional components, hooks
- [TypeScript](https://www.typescriptlang.org/) — strict mode
- [Vite](https://vitejs.dev/) — build tool and dev server
- [Panda CSS](https://panda-css.com/) — atomic CSS-in-JS, design tokens, CVA variants
- [Lucide React](https://lucide.dev/) — icons
- [Storybook](https://storybook.js.org/) — component development and documentation
- [Chromatic](https://www.chromatic.com/) — visual regression testing and Storybook publishing
- [Vitest](https://vitest.dev/) + [Testing Library](https://testing-library.com/react) — unit/hook tests
- [simple-git-hooks](https://github.com/toplenboren/simple-git-hooks) + [lint-staged](https://github.com/lint-staged/lint-staged) — pre-commit linting and formatting

## Getting started

```bash
npm install
npm run dev        # dev server with HMR
```

## Scripts

```bash
npm run dev        # dev server
npm run build      # production build → dist/
npm run preview    # preview production build
npm run storybook  # Storybook dev server
npm run lint       # ESLint on src/
npm run format     # Prettier on all files
npm run prepare    # regenerate Panda CSS types
npm test           # run tests with Vitest
```

## Project structure

```
src/
├── components/    # reusable UI (Button, Carousel, Header, Footer, …) + *.stories.tsx
├── sections/      # page sections (Hero, Skills, Testimonials, Career)
├── styles/        # CVA variant definitions
├── App.tsx        # root, theme provider
├── const.ts       # shared URLs and constants
└── main.tsx
styled-system/     # auto-generated by Panda CSS — do not edit
```

## Testing

Tests run with [Vitest](https://vitest.dev/) in a `jsdom` environment, using `@testing-library/react` for hooks/components. Test files sit next to the code they test (`useFocusFirst.ts` → `useFocusFirst.test.ts`).

```bash
npm test           # watch mode locally, single run in CI
```

## CI & Deployment

Every pull request and push to a non-`main` branch runs lint + tests via `.github/workflows/ci.yml`.

Push to `main` → GitHub Actions builds and deploys to GitHub Pages automatically (`.github/workflows/deploy.yml`).
